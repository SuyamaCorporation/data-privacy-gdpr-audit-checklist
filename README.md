# データプライバシーGDPR監査チェックリスト

GDPR・個人情報保護法のコンプライアンスチェックリストを構造化して実施・出力できるツール。

## 機能

- カテゴリ別チェックリスト（同意管理・データ保存・第三者提供・DPIA・インシデント対応・記録管理）全32項目
- チェック済み / 未対応 / N.A. の3択ステータス管理
- 全体スコア（%）と未対応項目一覧表示
- 優先度（高/中/低）フィルタリング
- 結果をMarkdown形式でクリップボードにコピー
- localStorageで進捗を自動保存

## 技術仕様

- バニラJS / Tailwind CDN
- XSSガード実装済み（escHtml関数）
- レスポンシブ対応
- 全インタラクティブ要素にaria-label付与
